# Grokking Deep Learning

Repository ini berisi hasil reproduksi kode, rangkuman teori, dan implementasi dari buku **Grokking Deep Learning** karya **Andrew W. Trask**.

Repository dibuat sebagai bagian dari tugas untuk memperdalam pemahaman dan keterampilan praktis dalam menerapkan konsep **Machine Learning dan Deep Learning** melalui reproduksi kode serta penjelasan teori.

## 📚 Tentang Buku

**Judul:** Grokking Deep Learning  
**Penulis:** Andrew W. Trask  
**Penerbit:** Manning  
**Tahun:** 2019  

Buku ini membahas konsep Deep Learning secara bertahap mulai dari konsep dasar neural network, forward propagation, gradient descent, backpropagation, hingga convolutional neural network, recurrent neural network, LSTM, dan federated learning.

## 🎯 Tujuan Repository

Repository ini dibuat untuk:

- Memahami konsep dasar hingga lanjutan dalam Deep Learning.
- Mereproduksi kode yang terdapat pada setiap chapter.
- Memahami cara kerja neural network melalui implementasi menggunakan Python dan NumPy.
- Menjelaskan teori yang digunakan pada setiap implementasi.
- Mendokumentasikan proses pembelajaran Deep Learning dalam bentuk notebook.

## 🛠️ Tools dan Teknologi

Beberapa tools dan teknologi yang digunakan:

- Python
- NumPy
- Jupyter Notebook
- Google Colab
- Keras
- GitHub
